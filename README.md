# Rivet 3 Component Guide

Component documentation for the Rivet 3 design system, published with GitHub Pages.

**Live site:** https://manselldesign.github.io/rivet-component-guide/

## Update the site

Run `./publish.sh` from this folder. It commits any changes and pushes them. The site updates in a minute or two.

## Files

- `components.json`: the A–Z component list (name, summary, status, last updated, Figma link)
- `docs/<slug>.md`: one Markdown file per component
- `token-changes.json`, `generated/rivet-tokens.css`, `rename-suggestions.json`: token guide files
- `img/`: images used in the docs
- `index.html`: the site itself
